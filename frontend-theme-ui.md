# Themes

Theme 1 (Dark Mode):

Primary Color: Deep, rich navy blue (#111625).

Accent Color: Vibrant electric blue (#0047FF) used for buttons, active states, and interactive elements, which pops sharply against the dark background.

Typography: Clean, white, and light-grey text for high contrast.

Theme 2 (Light Mode):

Primary Color: Clean, bright white (#F8FAFC).

Accent Color: The identical vibrant electric blue (#0047FF) is applied, creating a cohesive visual identity.

Typography: Dark-charcoal text for readability.

# Dark mode

- Background: #111625
- Surface: #171D2B
- Elevated: #1D2536
- Primary Blue: #0047FF
- Text: #F8FAFC
- Muted Text: #94A3B8
- Border: rgba(255,255,255,0.10)

# Light mode

- Background: #F8FAFC
- Surface: #FFFFFF
- Primary Blue: #0047FF
- Text: #0F172A
- Muted Text: #64748B
- Border: #E2E8F0

# Usage guidelines

1. Keep #0047FF consistent across both modes to maintain brand identity.
2. Use #111625 for dark mode background and #F8FAFC for light mode background.
3. Reserve blue for actions, active states, and links; avoid applying it to all headings, cards, and icons.
4. Use secondary surfaces for dark mode:
   - Surface: #171D2B
   - Elevated: #1D2536
   - Border: rgba(255,255,255,0.10)
5. Use neutral surfaces for light mode:
   - Surface: #FFFFFF
   - Border: #E2E8F0
   - Secondary text: #64748B
6. Define distinct hover, active, and focus blue states:
   - Default: #0047FF
   - Hover: slightly lighter
   - Active: slightly darker
   - Focus: blue ring
7. Use semantic colors only for status states:
   - Success: green
   - Warning: amber
   - Error: red
   - Info: blue
8. Keep glow effects subtle and occasional; avoid excessive neon styling.

Main UI identity should stay clean and blue-led with neutral surfaces, while glow effects are used sparingly as decorative accents.
