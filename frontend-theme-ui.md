- Side-by-Side Design System Showcase

# Themes

Theme 1 (Dark Mode):

Primary Color: Deep, rich navy blue (#111625).

Accent Color: Vibrant electric blue (#0047FF) used for buttons, active states, and interactive elements, which pops sharply against the dark background.

Typography: Clean, white, and light-grey text for high contrast.

Theme 2 (Light Mode):

Primary Color: Clean, bright white (#F8FAFC).

Accent Color: The identical vibrant electric blue (#0047FF) is applied, creating a cohesive visual identity.

Typography: Dark-charcoal text for readability.
