# CampusFlow
The Operating System for Student Organizations

# Tech Stack

Frontend        → React + Vite
Language        → TypeScript
UI              → Tailwind CSS + shadcn/ui
Backend         → Node.js + Express
Database        → PostgreSQL
ORM             → Prisma
Auth            → JWT / Better Auth
Validation      → Zod
Forms           → React Hook Form
Charts          → Recharts
QR              → qrcode
Payments        → Razorpay
Deployment      → Vercel + Render/Railway + Neon
